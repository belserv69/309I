# ZF-Proto — концепция проекта

**Рабочее название:** ZF-Proto (Zero-Forgetting Prototypes)
**Каталог:** `~/Projects/309I` (можно переименовать под кодовое имя)
**Дата создания:** 2026-08-13
**Родительские проекты:** `~/Projects/SOMA_Mind` (механика памяти), `~/Projects/CORAL` (признаки, данные, харнесс)

---

## 1. TL;DR

ZF-Proto объединяет лучшее из двух проектов:

- из **CORAL** — сильные признаки: замороженный ResNet-50 (GAP → 2048d) и 100-классовый бенчмарк mini-ImageNet;
- из **SOMA_Mind** — механику zero-forgetting: замороженные прототипы (`never_update`), per-class top-k запрос, O(N) batch-обучение.

**Главный эксперимент, который не делал ни один из проектов:** чемпионный рецепт SOMA
на RN50-признаках CORAL. Ожидаемый результат: точность ≥80% на 100 классах при ~нулевом
забывании — то, чего ни один родительский проект не достиг.

## 2. Предпосылки: куда уперлись родительские проекты

### SOMA_Mind (CIFAR-10, train 50 000)

| | |
|---|---|
| Лучший результат | **63.30%** (чемпион + TTA5, полный train 50k, ~9 ч CPU) |
| Потолок hand-crafted | 58.02% base / 63.3% с TTA — фундаментальный предел пространства признаков |
| Zero forgetting | ✅ достигнуто (`never_update=True`; чемпион C205: bird 0.3%, truck 0.0%) |
| Слабость | hand-crafted признаки (1402–1568d) принципиально ограничены ~63% |

### CORAL (mini-ImageNet, 100 классов, 50 train на класс)

| | |
|---|---|
| Лучший результат | **85.4%** P@last (frozen RN50 2048d + linear probe, ~42 мин) |
| Прототипная ветка | **68.0%** — на 17pp хуже probe-only (85.3%) |
| Забывание | ❌ не решено: cls0 93.3% → 80.0% (RN18); forgetting 0.133 (RN50) |
| Oracle (все классы сразу) | 86.2% → overhead инкрементальности всего 0.8pp |
| Слабость | SDR/VSA/sleep-ядро — балласт; прототипы не умеют пользоваться 2048d |

### Зазор, в который указывают оба проекта

- У SOMA есть **механика** zero-forgetting, но слабые признаки (потолок 63%).
- У CORAL есть **признаки** (85%+), но слабая механика (прототипы 68%, forgetting не решён).
- Прямая комбинация — прототипная память `never_update` на RN50-признаках — не проверялась никем.

## 3. Цель и гипотезы

**Цель:** система непрерывного обучения на mini-ImageNet-100, которая одновременно:

1. даёт точность ≥ 80% (P@last) — близко к CORAL hybrid 85.4%;
2. имеет забывание ≈ 0 — как SOMA C205;
3. работает на CPU, полный прогон за минуты, а не часы.

**Гипотезы:**

- **H1 (главная):** замороженные прототипы на RN50 2048d дают P@last ≥ 80% при
  forgetting ≤ 1pp. (CORAL-овские proto-only 68% измерены внутри его пайплайна с
  SDR-обвязкой и другой геометрией; чистый порт SOMA-механики должен быть существенно выше.)
- **H2:** механика переносима между признаками: тот же код памяти на SOMA-признаках
  CIFAR-10 воспроизводит ≈ 58–63% — критерий корректности порта.
- **H3:** аугментация обучения (4×) и test-time аугментация (TTA5) дают выигрыш и на
  признаках, как давали на пикселях.

## 4. Что берём из родительских проектов

| Компонент | Источник | Основание |
|---|---|---|
| Энкодер: frozen RN50, GAP 2048d | CORAL `coral/encoders/learned_encoder.py` | признаки почти линейно-сепарабельны (probe 85.3%) |
| Кэш признаков `rn50_2048.npz` (5000×2048 train, 3000×2048 test) | CORAL `benchmarks/.cache/` | прогон без torch, за минуты |
| Данные: mini-ImageNet 100cls, 50/30 на класс, 84×84 | CORAL | в 10 раз сложнее CIFAR-10 |
| Память: `PrototypicalMemory` (FAISS FlatIP, per-class top-k, threshold) | SOMA `scripts/test_soma_c205_per_class_exemplar.py` | доказанный zero forgetting |
| Режим `never_update` + `add_batch()` O(N) | SOMA | единственный механизм с доказанными 0% forgetting |
| Exemplar ring (per-class FIFO) | SOMA (чемпион C205) | страховка от confusion-пар классов |
| Метрики: фазовая таблица, P@last, per-class forgetting, oracle-зазор | CORAL ROADMAP | сразу видно цену инкрементальности |
| Дисциплина: `champions/` + `.log`, `best_model/`, честный лог, smoke→full | SOMA | защита от самообмана (урок feature-cache бага) |

## 5. Что НЕ берём и почему

| Компонент | Источник | Причина |
|---|---|---|
| SDR/VSA, sleep-консолидация, seniority bonus, margin/conf_ratio-тюнинг | CORAL | балласт: probe-only 85.3% против hybrid 85.6% |
| Hand-crafted signaturizer 1402d как основной путь | SOMA | потолок 63% измерен; остаётся только для кросс-валидации M3 |
| Dual-memory fusion (χ² color) | SOMA | исчерпана: 51.82% = base, сигнала нет |
| LDA на полном train | SOMA | провал на масштабе (52.86% против 63.3%) |
| Split-whiten PCA геометрия | SOMA | костыль под hand-crafted; RN50-признакам хватает L2-нормализации |
| 5-ГБ pkl-артефакты / 250k прототипов | SOMA | вердикт пользователя: «больше признаков, а не прототипов»; на 2048d достаточно 20–80k |

## 6. Архитектура

```
mini-ImageNet (84×84)
      │  [однократно] frozen RN50 → GAP
      ▼
кэш признаков .npz  (train 5000×2048, test 3000×2048)      ← CORAL
      │
      ▼
L2-нормализация
      ▼
PrototypicalMemory (SOMA):
  • never_update=True — каждый семпл = новый замороженный прототип
  • add_batch() — O(N) добавление (без O(N²) скана)
  • опционально: exemplar ring per-class
      │
      ▼
Запрос: FAISS FlatIP → per-class top-k (K=8) → mean similarity → argmax
  • опционально: TTA5 (усреднение по аугментированным вариантам)
      │
      ▼
Метрики: P@last, accuracy по фазам, forgetting per-class, oracle-зазор
```

## 9. Твёрдые правила (оплачены родительскими проектами)

1. **Чемпион священен.** Перед каждым новым экспериментом текущий лидер сохраняется в
   `champions/<имя>.pkl` (на диске, gitignored) + `champions/<имя>.log` (в git, с точной
   командой). Чемпион заменяется только после честной победы на чистом кэше.
2. **Smoke перед full.** Любой новый код-путь сначала проверяется на 10 классах / малых
   данных. Путь, дающий ~10% (random), означает неверную геометрию — полный прогон не жечь.
3. **Кэш хэширует данные.** Когда появится экстракция признаков (аугментации), ключ кэша
   обязан включать байты данных и test_len, а не только параметры. (Именно этот баг SOMA
   завышал все цифры на 3–4pp.)
4. **Логи — в `logs/`**, никогда в `/tmp` (умирают при перезагрузке).
5. **Git-коммит после каждого завершённого этапа**, даже без remote.
6. **Снимок в `best_model/`** (код + модель) после каждого багфикса.
7. **Честные числа:** подозрительно высокий результат → перепрогон на чистом кэше,
   прежде чем цитировать.

## 10. Риски и запасные пути

| Риск | Индикатор | Запасной путь |
|---|---|---|
| Прототипы на 2048d всё равно проигрывают probe (< 75%) | M2 | Метрическое обучение: контрастивная проекция 2048→128d поверх признаков (Direction A SOMA). НЕ кросс-энтропия — доказанный провал |
| Аугментации/TTA не переносятся в пространство признаков | M2 | Однократно предрассчитать признаки аугментированных изображений через torch (CORAL `.venv`), закэшировать с хэшем данных |
| 50 семплов/класс мало для плотного покрытия прототипами | M1–M2 | Аугментация 4×; herding replay (Direction B SOMA) вместо случайного отбора |
| Порт расходится с результатами SOMA | M3 | Дифф query-пути; известные грабли: threshold-фильтр, per-class K, порядок L2-нормализации |
